## 🏪 Multi-Vendor Marketplace

### How It Works

```
CUSTOMER PERSPECTIVE
Browse products from any vendor → Add to cart → Single checkout

BEHIND THE SCENES
Order splits into fulfillment groups → Each vendor prepares their items
→ Platform coordinates pickup → Rider collects from all vendors → Delivers together
```

## 💰 Multi-Vendor Order Handling

### Order Splitting

**Customer Cart:**
```
Product A - Vendor X - ৳500
Product B - Vendor X - ৳300
Product C - Vendor Y - ৳400
Product D - Platform - ৳200
Total: ৳1,400
```

**After Checkout Creates:**

1. **Parent Order** (Order #1234)
   - Customer: John Doe
   - Total: ৳1,400
   - Payment: bKash
   - Delivery: Standard
   - Single transaction record

2. **VendorOrder - Vendor X** (Group #1234-VX)
   - Items: Product A, Product B
   - Subtotal: ৳800
   - Status: Pending
   - Links to parent order

3. **VendorOrder - Vendor Y** (Group #1234-VY)
   - Items: Product C
   - Subtotal: ৳400
   - Status: Pending
   - Links to parent order

4. **Platform Items** (in parent order)
   - Items: Product D
   - Subtotal: ৳200
   - Handled by platform directly

### Status Synchronization

**Vendor Actions:**
- Each vendor manages their group independently
- Vendor can: Accept, Process, Ready for Pickup, Reject
- Cannot: Ship, Deliver, Cancel (platform controlled)

**Platform Actions:**
- Assigns rider once all groups ready
- Ships when rider picks up
- Delivers when customer confirms
- Cancels if customer requests

**Automatic Sync:**
- Parent "shipped" → All groups "shipped"
- Parent "delivered" → All groups "delivered"
- Parent "cancelled" → All groups "cancelled"

### Commission Calculation

```
Vendor X Revenue: ৳800
Commission (10%): ৳80
Vendor Payout: ৳720

Vendor Y Revenue: ৳400
Commission (15%): ৳60
Vendor Payout: ৳340

Platform Items: ৳200
Platform keeps: ৳200

Total Platform Revenue: ৳80 + ৳60 + ৳200 = ৳340
```

**Commission Rates:**
- Based on vendor subscription plan
- Deducted automatically
- Visible in vendor dashboard
- Paid out on schedule (weekly/monthly)

## 🎫 Discount Coupon System

### Two-Level System

**Store-Wide Coupons (Admin):**
- Apply to any/all products
- Created by platform admin
- Cannot be used with vendor coupons
- Example: `STORE20` - 20% off everything

**Vendor-Specific Coupons:**
- Apply only to that vendor's products
- Created by vendor (plan limited)
- Don't affect other vendors in cart
- Example: `VENDORX15` - 15% off Vendor X items

### Coupon Features

**Discount Types:**
- Percentage (1-100%)
- Fixed amount (৳X off)

**Restrictions:**
- Minimum order amount
- Maximum discount cap
- Specific products
- Specific categories
- First-time customers only
- Limit per customer
- Total usage limit

**Timing:**
- Start date/time
- End date/time
- Auto-activate/deactivate

**Tracking:**
- Redemption count
- Total discount given
- Revenue impact
- Customer list

### Coupon Validation

**Checked at Checkout:**
1. Code exists and active
2. Within date range
3. Not exceeded usage limits
4. Meets minimum order amount
5. Applies to cart items
6. Customer hasn't exceeded personal limit

**Error Messages:**
- "Coupon expired"
- "Already used maximum times"
- "Doesn't apply to your cart"
- "Minimum order ৳X required"

## 🌟 Featured Promotions System

### How It Works

**For Products:**
- Vendor pays to feature their product
- Duration based on subscription plan
- Limited slots per plan
- Appears: Homepage, Shop (top), Search results

**For Stores:**
- Admin grants featured store status
- Entire storefront promoted
- Appears: Featured Shops rail, Store directory (top)
- Given as: Gift or earned promotion

### Promotion Lifecycle

```
Vendor Requests → Platform Approves → Featured Period Starts
→ Daily checks → Still valid? → Yes: Continue | No: End
→ Slot freed for new promotion
```

**Auto-End Conditions:**
- Promotion period expires
- Subscription downgraded/expired
- Product unpublished/archived
- Vendor requested early end

### Placement Locations

**Featured Products:**
- Homepage carousel (position 1-3)
- Shop page (first row, highlighted)
- Search results (pinned top)

**Featured Stores:**
